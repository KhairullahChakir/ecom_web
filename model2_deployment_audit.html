1. Objective

This notebook bridges the gap between research and production. It converts the trained PyTorch Temporal Convolutional Network (TCN) into the ONNX (Open Neural Network Exchange) format, allowing for high-speed, CPU-optimized inference.

2. The Export Process

The model is exported with the following configuration: - Inputs: - page_ids: The sequence of action indices. - durations: The sequence of normalized time-deltas. - Dynamic Axes: Configured to support variable batch sizes, meaning the backend can process one session or thousands simultaneously without recompiling. - Opset Version: 12 (Ensures compatibility with internal ONNX runtime features used by TCN).

3. Production Artifacts

The output file is saved as: backend/models/exit_model_v1.onnx

This file is a standalone representation of the AI's logic, requiring no PyTorch dependencies to run. It is designed to be loaded by the FastAPI backend for real-time risk scoring.

4. Key Benefit

By moving to ONNX, we ensure that the Model 2 (Sequential) inference is as fast as Model 1, despite the added complexity of temporal convolutions. This is critical for the "Edge AI" goal where predictions must happen within milliseconds of a user's click.
