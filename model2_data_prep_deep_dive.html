Deep Dive: Model 2 Data Pre-processing

Analysis of 07_exit_model_data.ipynb

1. Objective

This notebook creates the foundation for Model 2 (Abandonment Detection). Unlike Model 1, which uses static session snapshots, Model 2 is a Sequential Model (Temporal Convolutional Network). It analyzes the order and timing of user actions to detect when someone is losing interest in real-time.

2. Event Mapping

The raw web events from the RetailRocket dataset are mapped to specific "Page Type" indices that the AI Brain understands: - view (Product View) $\rightarrow$ 1 - addtocart (Cart Intent) $\rightarrow$ 2 - transaction (Purchase) $\rightarrow$ 3 - padding (No action) $\rightarrow$ 0

3. The Sequential Pipeline

A. Sessionization (The 30-Minute Rule)

Raw clicks are grouped into unique sessions based on the visitorid. - Logic: If the gap between two events is greater than 30 minutes, a new session is started. - Filter: Only sessions with at least 2 events are kept (trash clicks are removed).

B. Sequence Construction (Fixed Window)

Sequential AI models require fixed-length inputs. This notebook uses a Sliding Window of 20 events. - If a session is longer than 20 events, it is capped. - If it is shorter, it is padded with 0.

C. Duration Normalization

The model doesn't just look at what you clicked, but how fast. - Formula: (timestamp_next - timestamp_current) / 1000 (Seconds). - Clipping: Any duration over 10 minutes (600s) is capped to prevent outliers from skewing the AI. - Normalization: All durations are scaled between 0.0 and 1.0.

4. Key Findings

  • Raw Scale: Processes over 2.7 Million events.
  • Session Yield: Generates 382,780 unique sessions.
  • Class Imbalance: The dataset has a 96.4% Abandonment Rate. This means only ~3.6% of sessions end in a purchase, posing a significant "Needle in a Haystack" challenge for the training phase.

5. Output Artifacts

The processed data is saved as Numpy binaries (.npy) in data/processed/: - X_page_real.npy: The sequence of action types. - X_dur_real.npy: The sequence of normalized durations. - y_abandon_real.npy: The binary labels (Abandoned vs. Purchased).
