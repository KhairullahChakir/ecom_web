Analysis of 08_exit_model_training.ipynb

1. Objective

This phase transitions from data engineering to Model 2 (Abandonment Detection) training. The goal is to train a Temporal Convolutional Network (TCN) to predict if a user will abandon their session based on the sequence and timing of their actions.

2. The Architecture: Temporal Convolutional Network (TCN)

Instead of standard Recurrent Neural Networks (RNNs) like LSTMs, this pipeline uses a TCN. - Causal Convolutions: The model ensures that the prediction for time $t$ only depends on events before time $t$ (no looking into the future). - Dilated Layers: These allow the model to have a very long "receptive field," meaning it can remember distant actions without the vanishing gradient problems of RNNs. - Embedded Representations: Actions are converted into vector indices, allowing the AI to learn the "meaning" of a product view vs. a cart addition.

3. Training Parameters (Full Dataset)

Following the audit, the model has been configured to train on the Full Dataset (380k+ sessions) for maximum coverage: - Optimizer: AdamW (The industry standard for transformer/TCN models). - Loss Function: BCEWithLogitsLoss (Ideal for binary "Abandoned" vs. "Purchased" classification). - Batch Size: 64. - Epochs: 5 (High learning rate ensures fast convergence on sequential patterns).

4. Key Performance Indicators (Training)

Initially, with 10k samples, the model achieved a Loss of 0.0022. - High Sensitivity: The model is extremely sensitive to the "pace" of a session. Fast click-throughs followed by a long pause are strong indicators of abandonment. - Resilience: Because it uses the X_dur (Duration) sequence, the model can tell the difference between a user reading a product description and a user who has walked away from their computer.

5. Deployment Readiness

The model weights are saved at each epoch, with the final state-of-the-art weights exported to backend/models/exit_model_tcn.pth. These weights are then ready for ONNX conversion and production serving.
