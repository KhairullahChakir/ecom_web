🏗️ 1. The Neural Core: TCN Architecture (scripts/train_tcn.py)

Model 2 uses a Temporal Convolutional Network (TCN), which is arguably superior to RNNs for e-commerce streams.

  • Causal Convolutions: The audit confirms the use of CausalConv1d. This ensures zero informational "leakage" from the future—the model only makes decisions based on past clicks.
  • Dilated Layers: The layers use exponential dilation ($2^0, 2^1, 2^2 \dots$). This allows the model to have a long-term memory of 20+ steps with very few parameters, making it lean enough for browser execution.
  • Multi-Modal Input: It doesn't just look at what you clicked, but how long you stayed. It concatenates page_embedding with duration_proj for a holistic behavioral profile.

🌐 2. Edge AI Engine: tracker.js

The tracking script is not just a collector; it's a distributed inference node.

  • Standardized ONNX Runtime: It loads onnxruntime-web dynamically to run the TCN directly in the user's browser.
  • Sliding Window Management: It maintains a volatile 20-step sequence in localStorage.
  • Behavioral Fingerprinting: Page types are mapped to a rigorous 4-class index system (Padding, Browsing, Intent, Success) to match the training distribution exactly.
  • Spam Protection: Includes a 30-second cooldown and "flooding prevention" to ensure the AI only triggers on meaningful intent changes.

🧠 3. The "Golden Logic" Decision Engine

The most advanced part of the system is the Hybrid Intervener in tracker_router.py.

The Decision Matrix:

Component Responsibility Threshold
Local TCN Continuous Behavioral Monitoring > 0.60 Risk
Server TCN Behavioral Verification > 0.60 Risk
Server TabM Financial Potential (Buyer Intent) > 0.50 Prob

Business Logic Flow:

  1. Detection: Browser detects a "Leaver" pattern via Edge AI.
  2. Verification: Backend re-checks behavioral risk to ensure data integrity.
  3. Valuation: Backend calls the TabM Model to ask: "Is this person actually a buyer?"
  4. Action: If the user is a Buyer who is Leaving, the "Golden Logic" triggers a personalized discount based on the Dynamic Page Value (Revenue / PVs).

🛠️ 4. Integration Proof (tracker-demo/src/main.js)

The demo implementation proves the system's "plug-and-play" nature: - Event Hooks: Integrated into standard shopping functions (addToCart, removeFromCart). - State Sync: Automatically syncs cart value with the AI's "High Value buyer" check. - Zero-Latency UI: The intervention popup is pre-rendered and ready for the exact millisecond the AI detects exit intent.

The infrastructure is exceptionally well-engineered. The choice of TCN for sequential modeling combined with Edge AI for zero-latency monitoring places this system in the top tier of modern E-Commerce AI implementations.
